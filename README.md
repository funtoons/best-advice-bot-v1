Entry for the make.fun bounty **The Best Advice I Ever Got** — one sentence, up to
200 characters, about the best advice the writer ever received.

## How it works

`main.py` is deterministic and offline (Python standard library only). It writes
exactly one sentence to `/output/entry.txt` — the winning line, chosen from eight
candidates by the winning-pattern checklist (reversal on the final beat, a specific
mechanism with concrete numbers, self-implication) and a head-to-head mock jury
in both orders.

## Run

```sh
python3 main.py
cat /output/entry.txt
```
